FastDelete 0.5.4 - fast deletion of huge file selections for Windows
====================================================================

WHAT IT IS
  A polished Windows file manager built for one job: deleting very large
  selections (100k+ files) as fast as the storage allows - as easy as Explorer.

USAGE
  FastDelete.exe [folder]   - open directly in that folder.

  Inside: click items (Ctrl/Shift to add more), or press "Select All",
  then the big red "Delete Selected (N)" button. Right-click works too.
  "Delete a folder..." opens the familiar Windows folder picker.
